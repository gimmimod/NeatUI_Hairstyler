# NeatUI Hairstyler

Hair and beard menus for Project Zomboid Build 42 as visual grids, in character creation and in game, styled to match NeatUI.

- Steam Workshop: https://steamcommunity.com/sharedfiles/filedetails/?id=3760534563
- Mod ID: `NeatUI_Hairstyler`
- Author: Gimmi

## Layout

- `workshop/` is the mod exactly as it is uploaded: `workshop.txt`, the preview and `Contents/mods/NeatUI_Hairstyler/`, with one folder per game build it supports.
- `art/` holds the cover and the images for the Steam page.
